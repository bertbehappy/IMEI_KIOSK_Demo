# 互動點餐機 Kiosk 操作簡易說明文件

本文件提供 Kiosk 點餐系統的前台使用者操作流程，以及後台管理員報表的使用說明。

## 一、 前台使用者操作流程

本系統專為銀髮族與一般民眾設計，具備字體放大、清晰按鈕與防呆機制。

1. **歡迎畫面**
   - 點擊畫面中央的 **「點我開始」** 大按鈕即可進入點餐流程。

2. **選擇餐點**
   - 根據畫面提示，點擊中央的餐點圖片即可加入餐點。
   - 點擊下方 **「下一步，確認餐點」**。

3. **確認訂單**
   - 畫面會顯示所選擇的餐點及數量總計。
   - 確認無誤後，點擊 **「確認點餐」**；若想取消可點擊 **「取消重新點餐」**。

4. **選擇付款方式**
   - 提供「現金」、「信用卡」、「悠遊卡/LINE Pay」等多元按鈕可供模擬點選。
   - 點選任一項後進入付款成功畫面。

5. **互動數位體驗與問卷**
   付款完成後，進入數位體驗防詐騙問卷與滿意度調查（共三題）：
   - **Q1:** 接到陌生來電，對方要你操作ATM，下列哪一個是正確作法？
   - **Q2:** 過去一年內，您有參加過像今天這樣結合數位科技的活動體驗嗎？
   - **Q3:** 今天活動的整體感受如何？
   - 每題皆須選擇選項後，才能點擊「下一題」或「送出問卷」。

6. **領取收據**
   - 問卷完成後，畫面將顯示取餐號碼，並模擬列印收據。
   - 倒數幾秒後，系統會自動回到首頁，準備服務下一位顧客。

## 二、 後台管理員操作說明 (問卷統計報表)

系統內建隱藏的管理員報表功能，可記錄並匯出顧客填寫的問卷資料。

### 如何進入後台報表？
1. **回到首頁 (歡迎畫面)**：確保畫面停留在「歡迎使用」與「點我開始」的首頁。
2. **觸發隱藏按鈕**：對著畫面上方的標題文字 **「歡迎使用」**，**連續點擊 5 次**。
3. **輸入密碼**：畫面會跳出管理員登入視窗，請輸入預設密碼：**`1234`**，並點擊「登入」。

### 報表功能介紹
- **查看紀錄**：登入後即可看見所有顧客填寫問卷的時間與作答結果。
- **匯出 CSV**：點擊右上方 **「匯出 CSV」** 按鈕，即可將歷史統計資料下載成試算表檔案，方便後續 Excel 統計與分析。
- **清除紀錄**：若需清空舊資料再進行下一波活動，可點擊 **「清除紀錄」**，系統將作二次確認後刪除現有資料。
- **關閉**：點擊 **「關閉」** 即可登出並返回前台首頁。

## 三、 技術與資料儲存說明

- **目前資料儲存方式**：問卷資料目前採用**瀏覽器本機儲存空間 (Local Storage)** 進行記錄。即使重新整理網頁，資料依然會保留在該台 Kiosk 設備上。
- **是否可連接地端資料庫？** 可以的。目前為獨立單機運作模式（Local Storage），若未來有建置地端伺服器 (Local Server) 或雲端資料庫的需求，可以擴充後端 API 服務，讓 Kiosk 將資料傳送至地端資料庫（例如 MySQL、PostgreSQL）統一進行長期儲存與跨機台資料彙整。
